Got a PayPal invoice you don't recognise?

Before you call any number in it, paste the invoice link here. HangUp reads the note and tells you if it looks like a callback scam.

Set it up for someone else

Helping a parent or friend? The HangUp browser extension shows this warning right on the PayPal invoice page.

Download the extension (.zip)

  1. Unzip the download. You get a folder called hangup-extension.
  2. In Chrome go to chrome://extensions, turn on Developer mode, click Load unpacked, and choose that folder.
  3. Click the puzzle-piece icon in Chrome's toolbar and pin HangUp. It already points at the hosted HangUp server, so there is nothing to configure.

Open the practice invoice (clearly marked as not from PayPal)

Be aware: the extension is not in the Chrome Web Store yet, so it has to be loaded by hand like this. It only runs on PayPal invoice pages, so the practice page will not show the banner: copy its note into the box above to see a result. The first check after the server has been idle can take up to a minute.

How HangUp decides

An AI reads the invoice text and fills in a short form (does it demand a callback? does it mention a charge you didn't make? does the brand match the sender?). Then plain code, not the AI, makes the call from that form. HangUp never moves money and never logs in to your PayPal.

HangUp is an independent tool. It is not made by or affiliated with PayPal. It cannot vouch for an invoice; it only looks for one scam pattern.
